How It Works

This player connects to Koryo.TV's edge servers to stream Korean Central Television (KCTV) live. The stream uses HLS (HTTP Live Streaming) with AES-128 segment encryption.

API Endpoints

  • GET /session/anon?quality=1080p — Create streaming session
  • GET /kctv/live/{uuid}.m3u8 — Get HLS playlist
  • GET /health — Server health check
  • GET /api/epg/b2ad0bb59619601b6dd7069a.dat — EPG data (gzip + header required)

EPG Data

The EPG API requires the X-Koryo-Epg: 1 header and returns gzip-compressed JSON. Each event contains Korean title, English title (when available), category, start/end times in Pyongyang time (UTC+9).

🚀 Deploy Your Own CORS Proxy on Vercel

Since Koryo.TV's APIs don't send CORS headers, you need a proxy. Here's how to deploy one on Vercel:

Step 1: Create api/proxy.js
export const config = { runtime: 'edge' };

export default async function handler(request) {
  const corsHeaders = {
    'Access-Control-Allow-Origin': '*',
    'Access-Control-Allow-Methods': 'GET, POST, OPTIONS, HEAD',
    'Access-Control-Allow-Headers': 'Content-Type, X-Koryo-Epg, Authorization, Accept, Referer, Origin, Cookie',
    'Access-Control-Allow-Credentials': 'true',
    'Access-Control-Max-Age': '86400',
  };

  if (request.method === 'OPTIONS') {
    return new Response(null, { status: 204, headers: corsHeaders });
  }

  const url = new URL(request.url);
  const target = url.searchParams.get('url');

  if (!target) {
    return new Response(JSON.stringify({ error: 'Missing url parameter' }), {
      status: 400, headers: { ...corsHeaders, 'Content-Type': 'application/json' },
    });
  }

  try {
    const fetchHeaders = {};
    ['x-koryo-epg', 'accept', 'referer', 'origin', 'cookie', 'user-agent'].forEach(h => {
      const val = request.headers.get(h);
      if (val) fetchHeaders[h] = val;
    });

    const response = await fetch(target, {
      method: request.method,
      headers: fetchHeaders,
    });

    const responseHeaders = { ...corsHeaders };
    ['content-type', 'content-encoding', 'content-length', 'cache-control', 'etag'].forEach(h => {
      const val = response.headers.get(h);
      if (val) responseHeaders[h] = val;
    });

    const setCookie = response.headers.get('set-cookie');
    if (setCookie) responseHeaders['set-cookie'] = setCookie;

    return new Response(response.body, {
      status: response.status,
      statusText: response.statusText,
      headers: responseHeaders,
    });
  } catch (error) {
    return new Response(JSON.stringify({ error: error.message }), {
      status: 500, headers: { ...corsHeaders, 'Content-Type': 'application/json' },
    });
  }
}
Step 2: Deploy
# Push to GitHub, then:
vercel --prod

🔒 Security Note

The proxy forwards cookies, which means sessions work correctly. However, be aware that anyone can use your proxy. Consider adding rate limiting or authentication if needed.
